THE FORMAT, NOT MAGIC
Source in. A fragment out.
A pako: link carries a JSON state with your code. Compression makes it smaller; Base64URL makes the compressed bytes portable in a URL fragment.
  1. 01JSON statecode + config
  2. 02zlibDEFLATE bytes
  3. 03Base64URLURL-safe text
  4. 04#pako:…share fragment

    
Share deliberately.
A share link contains the source. Compression is not encryption, and the link cannot be revoked. Opening it gives the chosen editor access to the fragment. Only open or share source you intend that destination to receive.
Know the boundaries.
This is a source codec, not a Mermaid parser or renderer. It does not check diagram syntax or promise compatibility with every editor. Unsupported formats and damaged data return an error.
UI source limit: 100,000 characters. Codec limits: 100,000 token characters, 512,000 uncompressed JSON bytes, 32 container levels. Link length limits vary by destination.
